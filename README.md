# Charm the Commuter: Forecast a City That Isn't

A one-line weather forecast entry for the make.fun bounty "Charm the Commuter: Forecast a City That Isn't". The program `main.py` writes a single forecast line to `/output/entry.txt` — for Gloomsbury, a city that does not exist: 10°C and rain until 5pm, then sunshine for exactly one commuter, with a warm bus, a short queue, and socks that stay dry.

> Gloomsbury: 10°C, rain until 5pm, then sunshine for exactly one commuter — the bus is warm, the queue is short, and your socks stay dry.

Run it with `python3 main.py`. It asserts the entry is 1–140 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
